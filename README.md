# Karthi Portfolio

A futuristic personal portfolio for **Karthikeyan — Vibe Coder & AI Product Builder**.

## Positioning

The site presents an AI-assisted product-building workflow focused on modern websites, product prototypes, business experiences, and automation systems. The visual direction uses a dark cyber-tech interface with glass panels, terminal-inspired UI, cyan/violet accents, and responsive layouts.

## Featured projects

- **Sugumar Portfolio** — cinematic video-editor portfolio with motion-led presentation
- **New Royal Tiles** — premium multi-showroom website with visualisation, calculators, branch discovery, and lead journeys
- **VIP-Hunter** — job-discovery automation using public employer ATS feeds, filtering, scoring, and scheduled workflows

## Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Radix UI
- Lucide icons
- EmailJS contact form
- next-themes

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Contact form

For production, configure these environment variables:

```env
NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key
```
